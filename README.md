# Smart-Hydrogel-Patch-PSBII-Teknik-Biomedis
Pengembangan dan karakterisasi hydrogel patch berbasis kolagen ikan, PVA, kitosan, dan ekstrak kubis ungu sebagai indikator pH alami untuk pemantauan kondisi luka. Repositori ini memuat dokumentasi formulasi, prosedur pembuatan, data hasil pengujian, analisis karakteristik fisik dan mekanik, serta evaluasi perubahan warna dan stabilitas produk.
